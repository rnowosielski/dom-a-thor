Dom-A-Thor Privacy Policy

Last updated: 5 October 2026

Dom-A-Thor is a browser extension that helps you preview house plot dimensions on a map. This policy describes what the extension accesses and how that information is used.

What the extension reads

  • On supported project catalog websites (for example extradom.pl, archon.pl, projektyzwizja.pl, mgprojekt.com.pl), the extension reads minimum plot dimensions and the plot diagram shown on the page when you open the extension popup.
  • If you enter a Polish land parcel identifier (Land ID), the extension sends that identifier to the public GUGiK ULDK service (uldk.gugik.gov.pl) to retrieve parcel geometry for map display.
  • To render the plot diagram, the extension may fetch image files from the same hosts shown on the project page (for example wpcdn.pl or the catalog site CDN).

What is stored locally

  • The Land ID you enter is stored in your browser using extension local storage so it persists between popup sessions on your device.
  • Mirror and display preferences you set in the popup are kept locally in your browser.

What we do not do

  • Dom-A-Thor does not send your browsing history to the developer.
  • Dom-A-Thor does not sell personal data.
  • Dom-A-Thor does not run analytics or advertising trackers in the extension.

Third-party services

Map tiles and parcel data come from third-party services you interact with by using the extension (GUGiK ULDK and the map tile provider shown in the popup). Their policies apply to those requests.

Contact

For privacy questions or commercial licensing, contact the maintainer via GitHub (@rnowosielski) or open an issue in the dom-a-thor repository.
